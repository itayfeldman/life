Conway's Game of Life — Architecture

Layered Python simulation: domain core · six engines · two frontends

Dependency Rule

  • • Domain has zero external imports
  • • All other layers import from domain
  • • No layer imports from presentation
  • • Toroidal wrap enforced in every engine
  • • Engine equivalence tested bit-for-bit

Six Engines

  • • bitpack — CSA tree on packed uint8
  • • convolution — scipy fftconvolve
  • • loop — pure Python nested loops
  • • pad_slice — np.pad + array slicing
  • • ix_index — np.ix_ fancy indexing
  • • roll — np.roll sliding window

Key Invariants

  • • All engines produce bitwise-identical output
  • • Toroidal (wrap-around) boundary mandatory
  • • Simulation depends only on protocols
  • • .cells files loaded lazily on first access
  • • Grid type: NDArray[int8]
